# Three-Project Demo Runbook

Canonical workspace:

- Registrar: `E:\registrarCanon_canon`
- Enrollment: `E:\EnrollLatest\enrollment3`
- Admission: `E:\AdmitLatest\admission`

## Demo Flow

1. Admission accepts applicant context
2. Enrollment finalizes pre-registration and payment
3. Registrar receives the student record and applies academic rules
4. Shift / withdrawal / accreditation / printing workflows are demonstrated in registrar
